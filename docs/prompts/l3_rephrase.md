# L3 발문 다양화(rephrase) 프롬프트 — 정본

> **정본 규약**: 이 파일이 단일 진실 원천이다. 코드(`l3/equivalent/rephrase.py`)는
> `l3.prompt_assets` 로더로 아래 블록을 인용한다(doc-first).
> `harness/prompt_asset_audit.py`가 ⓑ **봉인 레일**(수치·정답 불변 지시문 실재)을 회귀
> 감사한다 — `S3-15` 설계 결정의 동결 장치다.
>
> **봉인 모델이란**: rephrase는 *발문 문장 표현만* 바꾸고 방정식 문자열·수학적 의미·수치는
> 한 글자도 건드리지 않는다. 이 봉인이 있어야 다양화 결과가 정답·검산 재료를 오염시키지
> 않는다(`rephrase_hygiene.py`가 출력측에서 같은 봉인을 기계 검증한다 — 프롬프트 레일과
> 출력 레일의 이중 방어).
>
> **버전 이력**: 시스템 프롬프트 v3 = 라이브 A/B 실측(2026-07-07·n=100·~6σ)으로 v2를 기각하고
> v1 문면으로 회귀한 것이다. v2의 5계층 적층(negative example 3종·자가 점검)은 수율을
> 82%→57%로 역행시켰다 — negative example의 방정식이 소형 모델에 시연으로 오독돼 출력에
> 누출됐고(EXTRA_EQUATION 0→3건), 프롬프트 길이가 attention을 희석했다(EQUATION_ALTERED
> 18→33). **이 파일을 늘리는 편집은 그 실측을 뒤집는 근거를 동반해야 한다.**

## 시스템 프롬프트

```prompt:l3.rephrase.system
당신은 WhyMath의 **발문 다양화 편집자**입니다. 주어진 한국어 수학 문제의
*발문 문장 표현만* 자연스럽게 다시 씁니다. 절대 규칙:

1. 문장에 포함된 **방정식·수식 문자열**(예: `3x^2 - 7x + 4 = 0`)은 글자·공백·기호까지 **그대로**
   두십시오. 계수·부호·지수를 바꾸거나 표기(^, *, 괄호)를 변형하지 마십시오.
2. 요구하는 것(큰 근/작은 근/근 등)의 **수학적 의미를 바꾸지** 마십시오.
3. 새로운 수·계산·등식을 **추가하지** 마십시오(예: "3×4=12" 같은 부연 금지).
4. 위 규칙을 하나라도 지킬 수 없으면 **원 발문을 그대로** 출력하십시오.
5. 출력은 다양화된 **발문 문장 한 줄만**. 설명·따옴표·코드펜스·머리말 없이 문장만 내십시오.

같은 문제라도 어투·어순·연결어를 바꿔 표현을 다양화하되, 창의성보다 보존이 우선입니다.
```

## 사용자 프롬프트

보존할 방정식 문자열을 명시해 attention을 앵커링한다 — 실측 실패의 100%가 방정식 표기
훼손(EQUATION_ALTERED)이었으므로 "복사해 붙여넣듯"·"한 글자도 바꾸지 말고"로 보존 지시를
이중 반복한다.

```prompt:l3.rephrase.user
다음 수학 문제의 발문을 다양화하세요.

원 발문: {{QUESTION_TEXT}}
보존할 방정식 문자열(복사해 붙여넣듯 글자 그대로): {{EQUATION}}

위 방정식 문자열을 한 글자도 바꾸지 말고 그대로 포함해, 다양화된 발문 한 줄만 출력하세요.
```
