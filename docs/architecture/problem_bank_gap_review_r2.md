### ② 더 큰 반증 — 문제은행을 지킨다고 선언한 장치들이 선언대로 돌지 않는다

  성능 실측에 근거해 택한다. 조용한 절단을 남기지 않는 것이 요건이다.
- **변별력 의무**: 메타데이터 전용 출처 행 1건과 FAIL 코퍼스 문항 1건을 주입해 **후보에서
