```
[기존 경쟁]

[우리의 자리]
- "답 빠르게" 시장 X

```

## 5단계 시장 진입

### Phase 1 (6개월): 메타인지 사고력 시장
- 타깃: 중1~고1, 사고력 관심 학부모
- 매출: 무료 (β)
- 목표: 사용자 100~500명

### Phase 2 (12개월): 학교진도 + 수능
- 타깃: 풀 K-12
- 매출: 월 9,900원·29,900원
- 목표: 결제 1,000명

### Phase 3 (24개월): 영재 + 부모 보고서
- 타깃: 영재교육원·KMO 준비
- 매출: 월 49,900원 추가
- 목표: 결제 10,000명

### Phase 4 (30개월): B2B 학교·교육청
- 타깃: 자유학기제·영재교육원 학교
- 매출: 학생당 연 30,000원
- 목표: 학교 50, 교육청 3

### Phase 5 (36개월): 글로벌
- 타깃: 베트남·인도·영어권
- 매출: 글로벌 가격대
- 목표: 첫 해외 사용자 1,000명

## 가격 정책

| Tier | 월 가격 | 포함 |
|---|---|---|
| 무료 | 0원 | 사고력 일부·공적 OER·광고 없음 |
| 보급 | 9,900원 | 학교진도·내신·메타인지 |
| 프리미엄 | 29,900원 | + 수능 정밀 진단·부모 보고서·다중 풀이 |
| 영재 | 49,900원 | + 영재 트랙·KMO·Lean 옵션 |
| B2B 학교 | 학생당 연 30,000원 | + 교사 대시보드 |
| B2B 교육청 | 협의 | + 시범사업·맞춤 |

## 무료 티어가 핵심

- 공적 자산 명분 (사고력·메타인지)
- 신뢰 형성 (시간 들여 검증)
- 학교 진입로 (자유학기·영재교육원)
- 데이터 누적 (모델 개선 자산)
