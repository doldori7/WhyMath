# 전과목 확장 E축 실행 로드맵 v1 — 물리에서 영어까지 (E1~E6)

> **작성일**: 2026-07-05 | **상위 문서**: `business_plan_master_v1.md` 제4부 | **설계 정본**: `subject_expansion_readiness.md` · `subject_expansion_roadmap_review.md`
>
> 마스터플랜 제4부가 "무엇을·왜·어떤 순서로"를 정한다면, 이 문서는 **"각 과목을 실제로 어떻게 짓는가"** — 과목별 데이터 팩 명세·착수 트리거·게이트 지표·소요 모델 — 를 실행 수준으로 정본화한다.
>
> **불변 전제** (전 과목 협상 불가):
> - 과목 = 코드 포크가 아니라 **5종 데이터 팩**(성취기준·원자/개념·오개념·프롬프트·검증축). 모노레포 재편·노드 subject 내장 기각(확정 C1·C3).
> - 착수 순서는 **게이트가 결정**한다. 연도는 추정이며 직전 과목 파일럿 게이트 미통과 시 다음 과목 착수 금지.
> - **수학 완성(M6=S5 게이트) 통과 전 어떤 과목도 착수하지 않는다.**
> - 저작권 위험 서열 **국어 ≫ 사회 > 과학 ≥ 수학** 이 순서를 규정한다 — 위험 낮은 순 진입.

## 1. 과목 팩 6단계 플레이북 (전 과목 공통 공정)

E1 물리에서 이 공정 자체를 검증하고, 이후 과목은 **한계비용이 급감**한다(플레이북 학습 효과). 각 단계는 기존 코드/데이터 자산을 재사용하며, 신규 개발은 굵게 표시한 항목뿐이다.

| 단계 | 작업 | 재사용 자산 | 산출물 |
|---|---|---|---|
| ① 성취기준 수집 | NCIC 해당 교과 크롤·적재 + `SOURCE_CITATION` 과목 라벨 | `STANDARD_CODE_PATTERN`(과학 코드 수용 실측 완료)·`standard_loader` | `standards_<subj>_v1` 코퍼스 |
| ② 원자·개념 팩 | AREA 니모닉 등록 + 원자 백본 확장(교육적 압축 유지) | `atom_graph` 파이프라인·`_TOPIC_AREA_MAP` 레지스트리 규약 | `atom_graph_<subj>_v1` |
| ③ 오개념 시드 | 과목 접두 kebab-id + 연구 문헌 *분류 체계만* 참조 | 오개념 카탈로그·reactive retrieval·임베딩 subject 축 | `misconceptions_<subj>_v1` |
| ④ 검증 축 | SymPy 커널 유지 + 과목 검증 primitive 추가 | 3-tier 검증·정직성 규약(undecidable 보수 처리) | `l3/<verifier>.py` |
| ⑤ 시그니처·동등문제 | 수능 시그니처 방법론 재사용, 패턴 데이터만 과목 팩 | S2 동등문제 파이프라인·PRM·인간 검수 큐 | `problem_bank_<subj>` |
| ⑥ 파일럿 | 과목 중립 지표(오개념 해소율·답 미루기 깊이)로 소규모 검증 | S3 측정 하네스·WH-1 도구 루프 | KPI 베이스라인 + 게이트 판정 |

**공통 선행 게이트** (콘텐츠 1건 생성 전):
- [ ] 과목 저작권 매트릭스를 `licensing_safety.md`에 선행 등록
- [ ] 도메인 검수자 1인 트랙 확보 (수학 파트너가 겸하지 않음)
- [ ] 임베딩 namespace가 `<subj>` 추가를 스키마 변경 0으로 수용 (거버넌스 테스트)

> **팩 실측 스키마**: 6개 팩이 실제 저장소의 어떤 파일·필드로 채워지는지(성취기준 Collection JSON·원자 graph.json·오개념 M-id/kebab·검증 primitive·문제 JSONL)는 `docs/strategy/subject_pack_spec_v1.md`(과목 팩 명세서)에 코드 레벨로 정본화.

## 2. 과목별 데이터 팩 명세 (E1~E6)

### E1. 물리 — locked 1순위 (2028~)

**전략 근거**: SymPy 동치 커널·수식 AST·그래핑 자산 **재사용률 최대** → 확장 seam의 결함이 가장 잘 드러나는 검증용 첫 과목.

| 팩 | 명세 |
|---|---|
| AREA 니모닉 | `MECH`(역학)·`ELEC`(전자기)·`WAVE`(파동)·`THERMO`(열)·`MODPHY`(현대물리) — **예약 완료**(`subject_expansion_readiness.md` §4.1) |
| 검증 축 (신규) | `dimensional_consistency(expr, expected_dim) → {consistent/inconsistent/undecidable/parse_error}` · `sympy.physics.units` 기반 **형제 primitive**(커널 교체 아님) |
| 오개념 접두 | `phys-` · FCI(Force Concept Inventory) **분류 체계만** 참조(원문항 저작권 미사용) |
| 시각화 (신규) | `VisualizationStyle` ADD VALUE: 벡터장·파동그래프·자유물체도 · 2D 물리 시뮬(three.js WebView 비상구 재사용) |
| OCR 확장 | 회로도·자유물체도 도해 — 기존 PaddleOCR+Qwen3-VL에 도해 프롬프트 축 추가 검토 |
| 착수 트리거 | 이미 대장 예약(`readiness.md` §8): `dimensional_consistency`·`Problem.subject_area` 컬럼·물리 오개념 시드·PHY AREA 실등록 |
| 시장 | 2028 수능 통합과학 신설 = 기출 없는 첫 세대 진입 |

**게이트**: 물리 파일럿 D7·오개념 해소율이 수학 베이스라인 대비 유의미 열화 없음 + **6단계 소요 비용 실측**(이후 전 과목 견적의 기준선).

### E2. 화학 (2028H2~2029) — 플레이북 첫 재실행

**전략 근거**: 화학식·몰·평형은 SymPy 수식 검증의 연장. 물리 대비 **한계비용 급감을 실증**하는 단계.

| 팩 | 명세 |
|---|---|
| AREA 니모닉 | (물리 category 확정 후 동일 레지스트리 규약으로 등록 — 예: `STOICH`·`SOLN`·`ORGCHEM`·`EQUIL`) |
| 검증 축 | SymPy 유지 + 화학량론 등식·평형 상수 검산(수식 커널 재사용, 신규 primitive 최소) |
| 오개념 접두 | `chem-` · 입자 개념·보존 개념 등 문헌 풍부 → 메타인지 방법론 정합 높음 |
| 시각화 (신규) | 삼중 표상(거시·입자·기호) — LearningScene DSL 과목 spec · 분자 3D(three.js 재사용) |
| 게이트 | 6단계 소요가 물리 대비 **50% 이하**(학습효과 실증) + 통합과학 모드 물리·화학 cross-subject 진단 작동 |

### E3. 생물 (2029~) — 과학 팩 3부작 완성

**전략 근거**: 물리·화학·생물로 **통합과학 완전 커버**. 수식 비중 낮고 **개념 그래프·오개념 진단 비중 최대** → 계산기가 아닌 메타인지 코어가 본체인 WhyMath에 오히려 유리.

| 팩 | 명세 |
|---|---|
| 검증 축 (신규) | 수식 동치 부재 → **성취기준 근거 인용 기반 사실 검증**: 자체 코퍼스 내 근거 문장 RAG 인용 강제, 환각 시 undecidable 보수 처리(3-tier 정직성 규약 유지) |
| 오개념 접두 | `bio-`(예약) · 유전·진화·항상성 = 문헌상 가장 완고한 오개념군 |
| 시각화 (신규) | 계통도·생태 네트워크(D3.js 재사용) |
| 전략 분기 | "수학앱" → "수학·과학앱" — B2B 학교 계약 단가 상향 근거 |
| 게이트 | 사실 검증 축 undecidable 비율 허용선 이내(환각 0 원칙) + 과학 3과목 통합 진단 리포트 출시 |

### E4. 역사·사회 (2029~) — 통합사회 진입

**전략 근거**: 2028 수능 통합사회 신설 = 과학과 동일 "기출 없는 세대" 기회. 사료는 공공 저작물이라 언어 과목보다 저작권 위험 낮음 → 먼저 진입.

| 팩 | 명세 |
|---|---|
| 구조 | 역사 = **사건 네트워크**(원인·결과·동시성) — 새 엔진 아닌 개념 그래프 스키마 변형(관계 5~8개 제한 내, 시간 축은 노드 속성) |
| 교수학 변형 | Polya 역사 대응: **사료 읽기(이해)→가설(계획)→근거 검증(실행)→해석 성찰(반성)**. 소크라테스 "왜 그 사건이" 그대로 작동 |
| 검증 축 (신규) | 서술형 근거-주장 구조 평가(E6 영어의 선행 기술) |
| 오개념 접두 | `hist-` 신설: 연대 혼동·인과 오귀속·현재주의(presentism) |
| 코퍼스 | 사료 = 공공 아카이브·국사편찬위 라이선스 확인 |
| 게이트 | 서술형 평가 검수자 일치율 실측 + 사료 라이선스 매트릭스 법무 확인 |

### E5. 국어 (2029H2~2030) — 최고 저작권 위험·법률 선행

**선행 조건(착수 게이트)**: **법률 검토 예산·변호사 자문 선행 필수**. 문학 지문 = 작가 저작물, 위험 서열 최상.

| 팩 | 명세 |
|---|---|
| 진입 순서 | **비문학 독해·문법 먼저**(자체 창작 지문 가능) → 문학은 만료 고전부터 → 현대 문학은 라이선스분만 |
| 지문 수급 4트랙 | ①저작권 만료 고전 ②공공 텍스트 ③자체 창작 지문 ④라이선스 계약 — **법무 승인 후에만** |
| 구조 | 국어 = **기능 숙련 모델**(위계 약함 — 수학 prerequisite DAG와 다른 그래프 밀도) |
| 검증 축 (신규) | 오독 패턴 DB = 긴 한국어 텍스트 기반 → **임베딩 텍스트 규약 국어판 재설계**(NFKC·chunk 분리·`EMBEDDING_TEXT_FORMAT_VERSION` — `roadmap_review.md` §6.3 등록 항목) |
| 오개념 접두 | `kor-`: 지시어 오독·논리 비약·함축 오해 |
| 교수학 정합 | "왜 그 답인가" 소크라테스식 독해 = 국어 사교육 고질(감으로 찍기)의 정면 대안 → **슬로건이 국어에서 가장 문자 그대로 작동** |
| 게이트 | 지문 4트랙 법무 승인 + 오독 진단 검수자 일치율 + 독해 코칭 파일럿 D7 |

### E6. 영어 (2030~) — 최후순·아키텍처 거리 최대

**전략 근거**: 검증 권위가 SymPy도 사실 인용도 아닌 **루브릭 기반 LLM 평가**. "LLM 응답 검증 없이 학생 제공 금지" 금기 정합을 위해 평가자 LLM 자체의 검증 체계(PRM 언어판)가 필요 → 국어(E5) 언어 인프라 재사용 후 착수가 한계비용 최소 경로.

| 팩 | 명세 |
|---|---|
| 검증 축 (신규) | 루브릭 평가 하네스(WH-1 변형 — 평가 근거 강제 인용) + 인간 채점자 일치율(Cohen's κ 목표 사전 정의) |
| 포지셔닝 | **학교 영어(내신·수능) × 메타인지 오답 진단**으로 한정 — Riiid Santa(TOEIC AI·검증된 경쟁자) 성인 어학과 정면 충돌 회피 |
| 음성 축 | 듣기·말하기 — v3.0 음성 면접 시뮬레이션 자산 재사용 |
| 오개념 접두 | `eng-`: 모국어 간섭·문법 과잉일반화 |
| 게이트 | 루브릭 평가 인간 일치율(κ) 목표 도달 + 학교 영어 파일럿 |

## 3. cross-subject 개념 점화 지도 (이 앱만의 해자)

과목이 늘수록 가치가 커지는 유일한 축. **통합과학·통합사회 시대에 과목 간 개념 연결을 가진 학습 앱은 시장에 없다.**
이 축의 장기 지향(Education Knowledge Fabric)과 측정 지표 정의는 `knowledge_fabric_vision_v1.md`가 정본 (2026-07-16 신설 — 본 §의 불변식을 전부 승계).

- 물리 '순간속도' → 수학 '미분계수', 화학 '반응속도' → 수학 '순간변화율' 식 연결은 **기존 `prerequisite` 엣지 재사용**(관계 타입 신설 금지·플레이북 5~8개 제한).
- 과목 경계는 엣지 속성이 아니라 **양 끝 노드의 Overlay subject에서 유도** — 엣지 스키마 무변경.
- Minimal Reasoning Subgraph 추출 시 cross-subject 경계 정책(경계 넘어 depth 지속 vs 절단)은 물리 튜터링 소비처 등장 시 결정 — 양안 모두 depth ≤ 2·max_nodes ≤ 12~20 예산 안.
- `evidence_source`: 기존 값 rename 금지, `<subject>_education_literature` 패턴으로 값 추가.

## 4. 소요·순서 모델

### 4.1 과목당 소요 가설 (E1 실측이 이 표를 교체)

| 과목 | 신규 개발 무게 | 재사용률 | 상대 소요(E1=100 가정) |
|---|---|---|---|
| E1 물리 | 차원검증·2D 시뮬·도해 OCR | 최대(수식·그래핑) | 100 (기준선·플레이북 검증 포함) |
| E2 화학 | 삼중 표상 UI·분자 3D | 높음 | 50~60 (플레이북 재실행) |
| E3 생물 | 사실 검증 축·네트워크 시각화 | 중(개념 그래프 강함) | 55~70 (신규 검증축) |
| E4 역사·사회 | 서술형 평가·사건 네트워크 | 중 | 60~75 |
| E5 국어 | 임베딩 재설계·**법무 예산** | 낮음(언어 신규) | 80~100 + 법무 |
| E6 영어 | 루브릭 평가·음성 | 낮음(국어 인프라 재사용) | 55~70 (E5 후) |

> 표의 상대 소요는 **가설**이다. E1→E2 실측 비교가 플레이북 학습효과의 첫 증거이며, 이후 전 과목 견적을 실측으로 교체한다.

### 4.2 순서 확정 근거 요약

```
E1 물리 ── 엔진 재사용률 최대(검증용 첫 과목·locked)
  │        게이트: 6단계 비용 실측 = 이후 견적 기준선
E2 화학 ── 플레이북 첫 재실행·한계비용 급감 실증
E3 생물 ── 과학 3부작 완성(통합과학 완전 커버)·메타인지 강점 과목
  │        [분기점] "수학앱" → "수학·과학앱" (B2B 단가 상향)
E4 역사 ── 통합사회 진입·사료=공공(저작권 위험 < 언어)
```
