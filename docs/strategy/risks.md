# 리스크·대응

## Top 7 리스크

### 1. 콴다·메가스터디가 같은 방향 추격
**확률**: 중
**영향**: 매우 큼
**대응**: 
- 방법론·교수학은 자본으로 단기 복제 어려움 (1~2년 헤드스타트)
- 학회·정부·NRICH 협력으로 사회적 해자 구축
- Kiki의 메타인지 자산 *지속적 심화*

### 2. 입시 결과 검증에 1~2년
**확률**: 매우 높음
**영향**: 중
**대응**:
- 단기는 *진단·이해도*로 가치 입증
- Phase 1·2는 메타인지·사고력 (입시 무관)
- Phase 2 말~3에 수능 결과 데이터 누적

### 3. 학부모 "수능에 안 나오는 거?"
**확률**: 높음
**영향**: 큼
**대응**:
- 수능 모드 *반드시* 포함 (Phase 2)
- 사고력은 *부가* 포지셔닝
- 부모 보고서로 *진척* 가시화

### 4. LLM 환각
**확률**: 높음 (LLM 특성상)
**영향**: 매우 큼 (학생 학습 저해)
**대응**: 5중 검증
- PRM 단계 검증
- SymPy 수치 재확인
- 자기 일관성 (N회 → 다수결)
- 사람 수학자 검수 (샘플)
- *불확실하면 답 거부* 패턴

### 5. 정부 사업 변동성
**확률**: 매우 높음 (정권 영향)
**영향**: 중
**대응**:
- B2C 매출 안정성 *우선* 확보
- B2B는 다각화 (학교·교육청·자유학기)
- AI 디지털교과서 정책 변동 *모니터링*

### 6. Kiki의 수학 도메인 부족
**확률**: 사실
**영향**: 매우 큼
**대응**: **1순위 채용/영입**
- KAIST 영재교육원 출신
- 한국수학교육학회 활동가
- 영재교사 경력자
- 후보 3명 *Phase 0 마무리* 시점에 접촉

### 7. 미성년자 데이터 보호 사고
**확률**: 낮음 (대응 시)
**영향**: 매우 큼 (회사 존속)
**대응**:
- 14세 미만 부모 동의 미들웨어
- PII 분리 저장·암호화
- 보안 감사 (Phase 1 종료 시)
- 정기 침투 테스트 (Phase 2+)

## 게이트 미달 대응

각 Phase 게이트 미달 시 *Phase 연장*이 기본. *다음 Phase 진입 강행 금지*.

### 시그널
- 사용자 성장률 < 10% MoM
- LLM 비용 > 학생당 월 2,000원
- 학생 재방문율 < 20%
- 도메인 파트너 검수 실패

### 대응 액션
1. 1주 회고 (`/review` + MEMORY.md 분석)
2. 가설 재정립 (`/plan`)
3. 1개 우선순위로 좁히기 (병렬 작업 금지)
4. 2~4주 시도 → 재평가
5. 미달 지속 시 *피벗 또는 중단* 결정

## 윤리 리스크

### AI 과의존
**리스크**: 학생이 *AI 없이는* 못 푸는 상태
**대응**: 
- 답 미루기 원칙 *지속*
- 메타인지 코칭 *명시화*
- *AI 없이 풀기* 모드 옵션

### 정서적 의존
**리스크**: AI를 *인간 친구*처럼 의존
**대응**:
- AI임을 *명시*
- 정기적 *사람 도움* 제안 (선생님·부모)
- 위기 신호 시 사람 알림

### 학습 격차 심화
**리스크**: 결제 가능 학생만 이득
**대응**:
- 무료 티어 *충실하게*
- 자유학기·영재교육원 *공적 채널* 지원
- 정부 사업·교육청 시범 적극
