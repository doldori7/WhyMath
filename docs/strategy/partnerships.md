# 파트너십 전략

## 1순위 (Phase 0~1)

### 수학 교육 도메인 파트너
**왜**: Kiki의 *유일한 빈자리*

**후보군**:
- KAIST 영재교육원·수학교육과 출신
- 한국수학교육학회 활동가
- 영재학교·과학고 수학 교사
- 수학교육 박사 출신 (KICE·연구소·대학)

**역할**:
- 콘텐츠 검수
- 교수학 자문
- 학회·교육계 네트워크
- 도메인 인사이트

**조건**:
- 지분 또는 컨설팅 fee
- Phase 0 마무리 전 *3명 접촉*
- Phase 1 종료 전 *1명 확정*
- **게이트 통과 최소본**: 정규 파트너를 기다리지 말고 *검수 자문 1인(건당 fee)*으로 `G-domain-partner` 먼저 통과 후 정규 격상 → 모집 브리프·온보딩 절차는 `domain_partner_handoff_2026-07.md`
