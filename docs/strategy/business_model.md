## 1. 수익 모델 3축

WhyMath는 단일 수익원에 의존하지 않는다. B2C를 안정 기반으로, B2B 학원·B2B 학교를 확장축으로 둔다.

```
B2C Freemium      ← Phase 1.5~2 출시, 안정 기반 (매출 변동성 낮음)
B2B 학원 라이선스   ← Phase 3~4, 확장축 (객단가 높음, 영업 사이클 중간)
B2B 학교·교육청     ← Phase 4+, 공적 신뢰·정부 사업 연계 (영업 사이클 김)
```

CLAUDE.md 의사결정 우선순위상 **6번(비용·효율)이 1번(학생 안전·웰빙)을 양보시키지 않는다**. 따라서 아래 수익 모델은 *게이미피케이션 중독·답 빠르게 KPI* 같은 금기를 수익화 수단으로 삼지 않는다.

## 2. B2C Freemium

### 2.1 티어 구조 (가설)

| 티어 | 월 가격 (가설) | 포함 (요지) |
|---|---|---|
| 무료 | 0원 | 사고력 일부·공적 OER·광고 없음. 무료 티어는 *명분·신뢰·데이터 누적*의 핵심 |
| Premium | 4,900원 | 학교 진도·내신·메타인지 코칭·답 미루기 전 단계 |
| Premium Plus | 9,900원 | + 수능 정밀 진단·부모 보고서·다중 풀이 갤러리·우선 응답 |

> **주의 — PRD와 `market_positioning.md`의 가격 불일치**: PRD §12는 Premium 4,900원 / Premium Plus 9,900원을 제시한다. 그러나 WhyMath `market_positioning.md`의 기존 가격표는 보급 9,900원 / 프리미엄 29,900원 / 영재 49,900원이다. 이는 *가격 구조 미정* 상태를 의미한다. 두 안의 차이:
> - **PRD 안(4,900/9,900)**: 한국 학생 1인 다(多)앱 구독 환경에서 *가격 저항을 낮춰 침투율 우선*. 콴다 등과 가격대 직접 경쟁.
> - **기존 안(9,900/29,900/49,900)**: 메타인지·영재라는 *프리미엄 포지셔닝*에 부합, 객단가·LTV 우선.
> - **결정 필요**: 가격 구조는 Phase 1.5 결제 시스템 출시 전 *단일 결정*으로 확정해야 한다. β 사용자 지불 의향 조사(WTP survey)와 D7 retention 데이터를 입력으로 삼는다. 그 전까지 두 숫자 모두 *후보 가설*로 병기. → MEMORY.md 미해결 의사결정에 추가 권장.

### 2.2 전환 퍼널 가설

```
무료 가입 → 무료 사용(2~4주, 신뢰 형성) → Premium 전환 → Premium Plus 업셀
```

- 무료→유료 전환율 가설: **3~7%** (한국 교육앱 일반 범위, 검증 전)
- Premium→Premium Plus 업셀률 가설: **15~25%** (부모 보고서·수능 진단이 트리거)
- 핵심 전환 트리거: ① 내신 시험 D-30 ② 부모 보고서 첫 발송 ③ 다중 풀이 갤러리 노출

### 2.3 LTV 가설 (B2C)

> 아래는 *계산 예시*이며 실측 아님. 변수는 모두 Phase 1~2에서 측정해 교체한다.

| 변수 | 가설값 | 비고 |
|---|---|---|
| 평균 유료 객단가 (ARPPU) | 6,000~8,000원/월 | Premium·Premium Plus 가중 평균 |
| 평균 구독 유지 기간 | 8~14개월 | 학기·시험 주기에 연동, 방학 이탈 존재 |
| 결제 LTV (가설) | 약 5만~11만원 | ARPPU × 유지 개월 |
| 학생당 월 LLM 원가 목표 | 500~1,000원 | MEMORY.md KPI 베이스라인, 로컬 LLM 80% 처리 전제 |
| 기여 마진 (가설) | 객단가의 60~75% | LLM·인프라·결제 수수료 차감 후 |

**LTV/CAC > 3** 을 Phase 2 종료 게이트로 둔다(ROADMAP.md와 일치). CAC는 초기 *지인·오가닉* 중심이라 낮으나, 유료 광고 도입 시 재측정 필수.

## 3. B2B 학원 라이선스

### 3.1 가격 구조 (가설)

| 항목 | 가설 단가 | 비고 |
|---|---|---|
| 학원당 기본 라이선스 | 연 30만~50만원 | 교사 대시보드·반 편성·콘텐츠 접근 |
| 학생당 추가 | 월 2,000원/명 | 학원이 학생 수만큼 납부 |

- 예시(가설): 학생 60명 학원 → 기본 40만원 + (2,000원 × 60명 × 12개월) = 연 144만 + 40만 = **약 184만원/년**
- 학원 입장의 가치: 강사 1명이 못 하는 *개별 단계 진단*을 보완재로 제공. 학원 브랜드와 *경쟁이 아닌 보완*.

### 3.2 B2B 학원의 전략적 의미

- 객단가가 B2C 대비 높고, *학원이 영업·온보딩을 대행*하므로 CAC가 낮아질 수 있음
- 리스크: CLAUDE.md 금기 — "학원·인강 자료 데이터화 금지", "학원과 콘텐츠 통합 금지(브랜드 오염)". B2B 학원은 *WhyMath 제품을 학원이 구독*하는 형태이지, 학원 콘텐츠를 흡수하는 것이 아님. 이 경계를 계약서에 명문화.

## 4. B2B 학교·교육청

### 4.1 가격 구조 (가설)

| 항목 | 가설 단가 | 비고 |
|---|---|---|
| 학교 연간 라이선스 | 연 500만~1,000만원 | 학교 규모·과목 범위에 따라 |
| 교육청 시범사업 | 협의 | 시범 → 정식 전환 단계적 |

- `market_positioning.md`의 "학생당 연 30,000원" 산정과 호환: 학생 300명 학교 → 약 900만원. 학교 규모별로 정액·종량 혼합 가능.

### 4.2 B2B 학교의 전략적 의미

- 영업 사이클 6개월 이상(2026-05-13 결정 로그) → Phase 4에서 본격화
- 정부 사업(아래 §6)·자유학기제·영재교육원과 연계되는 *공적 신뢰 축*
- 무료 티어가 학교 진입로 역할(`market_positioning.md`)

## 5. 24개월 매출 시나리오 (보수적·가설)

> **이것은 예측이 아니라 시나리오다.** 사용자 수·전환율·단가는 모두 가설이며, 각 Phase 게이트에서 실측으로 교체한다. 보수적 가정을 채택한다.

### 5.1 가정 (보수적)

- Phase 1(0~6개월): 무료 β만, 매출 0 (ROADMAP.md와 일치)
- Phase 1.5~2(6~12개월): 결제 출시, 결제 사용자 1,000명 도달(Phase 2 게이트)
- Phase 3(12~24개월): 결제 사용자 10,000명 도달(Phase 3 게이트), B2B 학원 소수 진입

### 5.2 시나리오 표 (누적 24개월, 보수적)

| 구간 | 결제 사용자 (가설) | B2C 월매출 (가설) | B2B 누적 (가설) | 비고 |
|---|---|---|---|---|
| 0~6개월 | 0 | 0 | 0 | β 무료 |
| 6~12개월 | 100 → 1,000 | 60만 → 600만 | 0~소액 | 결제 시스템 출시·램프업 |
| 12~18개월 | 1,000 → 4,000 | 600만 → 2,400만 | 학원 5~15곳 | 영재 트랙·다중 풀이 출시 |
| 18~24개월 | 4,000 → 10,000 | 2,400만 → 6,000만 | 학원 15~40곳 | B2B 학원 본격, 학교 시범 시도 |

- **24개월 누적 매출 가설: 약 5억원대** (보수적). B2C 누적 + B2B 학원 누적의 합. ROADMAP.md "3년 후 월 매출 5억~15억"으로 가는 *경로상의 중간 지점*.
- 낙관·비관 시나리오는 별도 재무 모델에서 관리. 본 문서는 *보수적 단일선*만 제시.

### 5.3 시나리오를 흔드는 핵심 변수

`risks.md`의 5개 핵심 가정과 직결. 특히:
- 무료→유료 전환율(3~7% 가설)이 1%p만 빗나가도 매출선이 크게 이동
- D7 retention(`risks.md` 가정 ①)이 30% 미만이면 결제 사용자 램프업 자체가 무너짐
- LLM 한국 수학 풀이 정확도(`risks.md` 가정 ④)가 낮으면 환불·이탈로 LTV 하락

## 6. 자금·인력 계획 (PRD §16)

### 6.1 Phase별 자금 출처 (가설)

| Phase | 기간 | 주요 자금 출처 (가설) | 비고 |
|---|---|---|---|
| Phase 0~1 | -1~6개월 | 자기자본 + **예비창업패키지** | MVP·검증 단계. 정부 초기창업 지원이 적합 |
| Phase 1.5~2 | 6~12개월 | **TIPS** 추천 + 초기 매출 + 엔젤/시드 | TIPS는 운영사 추천 필요 — 별도 트랙 |
| Phase 2~3 | 12~24개월 | 시드~프리A 투자 + 매출 + **AI 바우처** | AI 바우처는 *수요기업* 자격 검토 |
| Phase 3~4 | 24~30개월 | 시리즈A + B2B 매출 + 정부 R&D 과제 | 교육부·과기정통부 R&D 매핑 |
| Phase 4+ | 30개월~ | 시리즈A/B + B2B·정부 사업 매출 | 자생 가능 구간 목표 |

> 위 자금 출처는 *후보*이며, 각 사업의 공고·자격 요건·시기는 매년 변동한다. 신청 전 최신 공고 확인 필수.

### 6.2 정부 R&D·지원사업 매핑 (가설·후보)

| 지원사업 | 적합 Phase | 적합도 메모 |
|---|---|---|
| 예비창업패키지 | Phase 0~1 | 예비창업자·초기 단계. 사업화 자금 |
| 초기창업패키지 | Phase 1~2 | 창업 3년 이내. 예비창업 후속 |
| TIPS | Phase 1.5~2 | 운영사 추천 필수. 딥테크·기술창업. R&D + 투자 연계 |
| AI 바우처 | Phase 2~3 | AI 솔루션 *수요기업* 또는 *공급기업* 트랙 확인 필요 |
| 데이터 바우처 | Phase 1~2 | 데이터 가공·구매 지원 — NCIC·교과서 매핑 파이프라인과 연계 가능성 |
| 교육부·과기정통부 R&D | Phase 3~4 | AI 디지털교과서 정책 연계 시 시너지(단, 정책 변동성 — `risks.md` 가정 ⑤) |
| 시도교육청 시범사업 | Phase 4+ | 강원도교육청 등(`partnerships.md` 2순위) |

## 7. 변호사·전문가 자문 필요 사항

- B2B 학원·학교 계약서의 *데이터 권한·콘텐츠 경계* 조항 → **변호사 자문 필수** (`docs/legal/` 참조)
- 정기결제(구독) 약관·청약철회·미성년자 환불 → **변호사 자문 필수** (`docs/legal/regulatory_checklist.md`)
- 정부 R&D 과제의 IP 귀속·기술료 조건 → 과제 협약 단계에서 검토
- TIPS·투자 유치 시 주주간 계약 → 법률·회계 자문 필수
