## 1. 문서 개요

### 1.1 작성 배경
WhyMath PRD v1.1에서는 GSM8K 기반 Socratic 튜터링의 기본 아키텍처를 정의했다. 그러나 한국 수능 수학 시장의 고유 특성을 충분히 반영하지 못했다는 한계가 있었다. 본 v1.2는 **한국 수학 입시 시장의 100가지 특성**을 체계적으로 발굴하여, 각각이 WhyMath의 어떤 기능에 매핑되는지 정리한다.

### 1.2 핵심 통찰 요약
- 한국 수능 수학은 **외산 LLM이 못 푸는 시그니처 패턴**(귀납적 수열, 합성함수 미분, 조건 나열형 발문)이 존재 → WhyMath의 진짜 모트
- 시장 규모는 약 **52만 명** (재학생 32만 + N수생 20만), 결제 의향 매우 높음
- 콴다·매스프레소·오르조 등 직접 경쟁사 존재 → **"답이 아닌 풀이 과정"** Socratic 차별화 필수
- **2028 수능 대개편**으로 시장이 한 번 더 재편 예정 → v2.0 분기 로드맵 필수

### 1.3 본 문서의 사용 방법
- 개발 우선순위 결정 시 **매핑 매트릭스**의 P0/P1/P2 참고
- 콘텐츠 데이터 작업 시 **우선순위 매트릭스** 참고
- 마케팅·시장 진입 결정 시 **페르소나 5종** 참고

## 3. 사용자 페르소나 5종

### 3.1 페르소나 A: "30번이 안 풀리는 일반고 고3"

- **이름**: 김민준 (가명), 18세, 남, 경기 양평 거주
- **학년**: 일반고 고3
- **학력**: 수학 모의고사 3등급 (백분위 75)
- **상황**:
  - 학원 다니지만 한 명의 강사가 80명 일괄 강의
  - 13~14번까지 정답률 90%, 15·22번부터 막힘
  - 30번은 1~2번 풀어보고 포기
- **현재 학습 도구**: 메가스터디 인강 + 콴다 (답만 빨리 봄)
- **결제 의향**: 월 1~3만 원
- **WhyMath에 기대하는 것**:
  - 30번을 끝까지 풀어내는 사고 과정 코칭
  - 막혔을 때 답이 아닌 힌트 제공
  - 매주 약점 단원 진단

### 3.2 페르소나 B: "의대 노리는 자사고 N수생"

- **이름**: 박서연 (가명), 20세, 여, 서울 강남 거주
- **학년**: 재수생 (자사고 출신)
- **학력**: 수능 수학 1등급 컷 +5점 (백분위 95)
- **상황**:
  - 일타강사 라이브 패스 + 시대인재 서바이벌 등록
  - 22번·30번 정답률 70%, 마지막 변별 점수 필요
  - 멘탈 관리가 핵심 (지난해 수능 직전 슬럼프 경험)
- **현재 학습 도구**: 인강 + 대치동 학원 + 종이 오답노트
- **결제 의향**: 월 5~10만 원 가능
- **WhyMath에 기대하는 것**:
  - 30번 변형 문제 무한 생성
  - 풀이 시간 분석으로 시간 관리 코칭
  - 멘탈·슬럼프 대응 (D-100 코칭 모듈)

### 3.3 페르소나 C: "검정고시 출신 N수 도전자"

- **이름**: 이지훈 (가명), 22세, 남, 강원 춘천 거주
- **학력**: 고졸 검정고시 + N수 2회
- **상황**:
  - 학원 비용 부담 (월 100만 원 학원비 불가)
  - 정시 단독 전략, 수학에서 점수 만들어야 함
  - 자기주도 학습 능력 보통, 강사 없이 막힐 때 외로움
- **현재 학습 도구**: EBSi 무료 강의 + 자이스토리
- **결제 의향**: 월 5만 원 이내
- **WhyMath에 기대하는 것**:
  - 학원 대체 가능한 1:1 코칭
  - 한 문제를 끝까지 같이 풀어주는 동반자
  - 수능 1년 사이클 (3-6-9-11월) 학습 계획 자동 생성

### 3.4 페르소나 D: "학종 노리는 일반고 고2 학생"

- **이름**: 최예린 (가명), 17세, 여, 인천 거주
- **학년**: 일반고 고2
- **학력**: 수학 내신 2.5등급, 모의고사 3등급
- **상황**:
  - 정시보다 수시 학종 노림
  - AI/데이터 학과 진학 희망 → 인공지능 수학 선택
  - 세특에 적을 만한 탐구 활동 부족
- **현재 학습 도구**: 학교 + 학원 + 굿노트 (아이패드)
- **결제 의향**: 월 2~4만 원
- **WhyMath에 기대하는 것**:
  - **자유연구 주제 자동 추천** (확률 단원 → 베이즈 정리 → 의료 진단)
  - 세특용 학습 기록 250자 자동 정리
  - 진로별 맞춤 과목 선택 코칭

### 3.5 페르소나 E: "홈스쿨링 영재"

- **이름**: 정하늘 (가명), 16세, 남, 충남 거주
- **학년**: 비인가 대안학교 / 홈스쿨링
- **학력**: KMO 동상 (중등부), 검정고시 만점
- **상황**:
  - 학교 다니지 않아 강의 접근 어려움
  - 진도와 깊이가 본인 호기심 따라 들쭉날쭉
  - 학종 어려움 → 수능 정시 + 영재고 입시 노림
- **현재 학습 도구**: 유튜브 + 책 + 부모님 지도
- **결제 의향**: 가족 결제, 월 5~10만 원 가능
- **WhyMath에 기대하는 것**:
  - **수학 영재 트랙** (KMO 입문, 대학 미적분학 사전 학습)
  - 진도와 무관하게 자유롭게 학습할 수 있는 환경
  - 부모가 학습 상태를 한눈에 보는 대시보드

## 끝맺음

이 문서는 한국 수학 입시 시장의 100가지 특성을 WhyMath PRD의 구체적 기능 요구사항으로 매핑한 결과물이다.

**핵심 인사이트 7가지**(요약):

1. **차별화 모트**: 한국 시그니처 패턴(귀납적 수열, 합성함수 미분, 조건 나열형)이 외산 LLM의 사각지대
2. **시장 진입점**: 일반고 고3 (페르소나 A) → 검정고시·학종 (페르소나 C, D) → 자사고·영재 (페르소나 B, E)
3. **콘텐츠 우선순위**: 평가원 + EBS + AIHub + 자체 생성 (모두 P0)
4. **기술 핵심**: Qwen3-VL 멀티모달 + Claude Socratic + ChromaDB 개념 그래프
5. **2028 분기 필수**: v2.0에서 2022 개정 교육과정 완전 전환
6. **사회적 미션**: 사교육 격차 해소 = 비즈니스 모델의 본질
7. **장기 미션**: 수능 점수가 아닌 "대학에서도 살아남는 수학 사고력"
