## ① 과제 명칭
S3-01 파일럿 코호트 착수 — 시범 학생 5~10명 모집 → 미성년 동의 → 2주+ 실사용 → KPI 베이스라인 기록.

## ② 목적
진짜 학생에게 앱을 노출해 **KPI 베이스라인을 실측**한다. S3 탈출 게이트 3종(①KPI 베이스라인 ②**재사용 의향 ≥60%** ③세션당 비용 손익 범위)의 근거. **S3-01은 트랙 게이팅 노드** — 이게 열려야 S4(K-12 완성)→S5로 이어진다.

## Step D — 개인정보 리허설 (검증된 엔드포인트·`src/backend/whymath_backend/api/me.py`)
파일럿 전 **테스트 계정**으로 로그인해 아래 흐름이 실제 동작하는지 확인(인증 JWT 필요·실계정 금지):
- `GET /v1/me/export` — 내 데이터 내보내기
- `DELETE /v1/me` — 계정 전체 삭제 · 개별: `DELETE /v1/me/sessions|dialogues|assessments/{id}`
- `GET /v1/me/deletions` — 삭제 감사 로그

성공 기준: export가 JSON 반환·delete 후 재조회 시 데이터 부재. (앱에 "내 데이터" UI가 있으면 그걸로 리허설.)
