# 차별화·해자

## 5중 해자

### 1. 데이터 해자
**자산**: NCIC + 학교알리미 + 검정교과서 매핑 + 평가원 + KMO 디지털화
**축적 시간**: 1~2년
**복제 비용**: 매우 높음 (대기업도 *지속적 큐레이션* 필요)
**B2B 가치**: 라이선싱 가능

### 2. 방법론 해자
**자산**: 메타인지·소크라테스·NRICH-style·Polya 시스템
**한국 경쟁자**: 거의 없음
**복제 비용**: 자본 X, *교수학 깊이* 필요
**Kiki 자산**: 기존 메타인지 튜터 직접 활용

### 3. 비용 해자
**자산**: Phaiakes9 (Ryzen AI Max+ 395, 128GB) 로컬 LLM
**평균 호출 비용**: 클라우드만 사용 대비 1/10
**중요성**: 클라우드 비용 폭발기에 *유일한 흑자 모델*

### 4. 신뢰 해자
**자산**: PRM 단계검증 + 수학자 검수 + Lean 옵션
**경쟁자 미달**: 콴다·매스프레소는 *결과만* 검증
**고객 가치**: 학부모 신뢰 (특히 영재·내신)

### 5. 사회적 해자
**자산**: 학회·정부·NRICH Cambridge 협력 (장기)
**효과**: 인용·권위·공적 신뢰
**시간 축적**: 3~5년

## 콴다와 정면 충돌 회피

```
콴다 영역: "답 빠르게" → 사진 → OCR → 풀이 즉시
우리 영역: "생각하는 법" → 풀이 → 단계 진단 → 다음 발상 유도
```

같은 문제, *다른 가치 제안*.

## 메가스터디와 다른 자리

```
메가스터디: 콘텐츠·강사·시간 (공급)
우리: 진단·코칭·메타인지 (개인화)
```

상호 보완. 학생은 강의 + 진단 둘 다 가능.

## Kiki만 가진 자산 조합

한국에서 이 조합을 가진 사람이 거의 없음:

- ✅ AI 인프라 (Phaiakes9 로컬 LLM)
- ✅ Flutter 앱 개발 (Atlas Odyssey·BeatBuddy)
- ✅ 메타인지 튜터 자산 (이미 핵심 IP)
- ✅ Claude Code 하니스 (콘텐츠 자동화)
- ✅ 정부 사업 경험 (공공보건)
- ✅ 데이터 파이프라인 (AVAC)
- ❓ 수학 교육 도메인 — **유일한 빈자리, 파트너로 해결**
