## 0. 원칙 — 안전의 정의 교체

**"인간이 봤으니 안전"은 측정된 적 없는 가정이다.** 안전의 정의를
"누가 봤는가"에서 **"무엇이 측정으로 증명됐는가"**로 교체한다.

- 인간 검수는 공짜 안전이 아니다 — 표본적(전수 불가)·비결정론적(재검수 일치 미보장)·
  무보증(자기 오류율을 모름)이라는 실측 가능한 결함을 가진 *하나의 검출기*일 뿐이다.
- 기계 게이트는 아래 6축에서 인간이 물리적으로 도달 불가능한 기준을 달성할 수 있고,
  그 달성 여부는 선언이 아니라 §3의 강등전으로 증명한다.
- 어떤 게이트도 측정 없이 "인간 검수 대체"를 선언할 수 없다(쌍둥이 금기 — CLAUDE.md).
  측정 미달·판정 불가(undecidable)는 인간 큐로 정직 폴백한다(모르면 모른다).

## 1. 인간 검수능력의 상한 (넘어설 대상)

| 축 | 인간 검수자의 물리적 상한 |
|---|---|
| 처리량 | 라운드당 30문 표본(로드맵 S2 게이트 ②) — 전수 불가 |
| 반례 탐색 | 문항당 머릿속 반례 ~3개 |
| 관점 수 | 1인 = 1관점 |
| 재현성 | 같은 문항 재검수 시 판정 일치 미보장(피로·순서 효과) |
| 오류 보증 | 자기 오류율 미측정 — "괜찮아 보임"(무보증 점추정) |
| 지속성 | 1회 이벤트 — 승인 후 재검수 없음(정본 변경에 무반응) |

## 2. 초인간 검증 기준 6축 (안전의 새 정본)

| 축 | 기준(수치) | 인간 상한 | 구현 |
|---|---|---|---|
| **S1 전수성** | 학생 노출 문항의 기계 검증 커버리지 **100%**(전 문항·전 스텝 — Tier1 답 검산+Tier2 단계 동치) | 표본 30문 | `l3/verify_answer`·`l3/verify_solution` (배선 완료·590문 전수 통과). 사각지대(unverifiable)는 PRM Tier3로 축소(라이브 트랙) |
| **S2 적대성** | 문항당 수치 반례 공격 **≥10,000 시행**(결정론 grid+jitter sweep) 반례 0 | ~3안 | `l3/equivalent/counterexample_fuzz.py` |
| **S3 독립 다관점** | 원리가 다른 검증기 **K≥3 전원 통과**(심볼릭 SymPy·수치 fuzzing·프로세스 PRM) + **생성자≠검증자 주체 분리**(발문-수식 정합 독립 감사 — 생성기 자기신고 태그 불신) | 1관점 | `l3/equivalent/retag.py` (StatementConsistencyAuditor·TagAuditor 좌석) |
| **S4 재현성** | 동일 입력 재판정 일치율 **100%**(결정론·seed 고정) | 미보장 | 전 게이트 순수 함수·`_POOL_SEED` 문화·회귀 테스트 동결 |
| **S5 보증된 오류 상한** | 결함율을 점추정이 아니라 **Wilson 95% 단측 상한**으로 보고, 상한 **≤ 2%** | 무보증 | `harness/corpus_audit_eval.py`(감사 라벨 → 상한 게이트·exit 0/1) |
| **S6 상시성** | 전 코퍼스 자동 재검증 주기 **≤ 24h** + 정본 변경 시 전수 재검증 | 재검수 0회 | `harness/corpus_reverify.py` + CI 야간 잡 |

**게이트 판정 규약**: 각 축의 게이트는 CLI exit 0(통과)/1(미달)로 판정한다(judge flip
게이트 선례 — `l4/misconception/semantic_eval.py`). 표본 하한 미달·판정 불가는 "통과"가
아니라 "미달"이다(작은 표본 거짓 해금 차단 — Wilson, 슬라이스 68 선례).

## 3. "넘어섬"의 증명 — 결함 주입 강등전

기계를 채점할 정답지(GT)를 인간 라벨에 의존하면 순환이다. 해법 = **결함 주입**
(mutation testing 원리): 결함을 **우리가 의도적으로 주입**하므로 정답을 이미 안다 —
인간 라벨 0건으로 GT가 성립한다.

### 3.1 결함 6종 (주입기: `l3/equivalent/defect_seeder.py`)

| # | defect_class | 내용 | 현 스택 검출 예상 |
|---|---|---|---|
| ① | `answer_error` | 정답 오기(계산 오류) — 진답+1 | Tier1 검출 |
| ② | `explanation_slip` | 해설에 거짓 수치 등식 삽입 | 위생 게이트 검출 |
| ③ | `condition_mismatch` | 조건식 변조(답이 더 이상 해가 아님) | Tier1 검출 |
| ④ | `standard_tag_error` | 성취기준 태그 오기 | 동등성 성분 강하 → 차단 |
| ⑤ | `distractor_misattribution` | 오답 선지 오개념 오귀속 | 동등성 성분 강하 → 차단 |
| ⑥ | `statement_mismatch` | 발문 표시 수식 ≠ 검산 조건 | **S3 감사기 전 미검출**(정직 공백 — StatementConsistencyAuditor가 담당) |

### 3.2 강등전 절차

1. **셋 구성**: 결함 100문 + 무결함 100문(N≥200), seed 고정 결정론 —
   `harness/defect_detection_eval.py --emit-blind`가 블라인드 셋 + 분리된 정답지를 산출.
2. **양측 실행**: 같은 셋을 기계 스택(S1~S3 게이트)과 인간 검수자에게 블라인드 제출.
3. **판정** (CLI가 판정문 출력):
   - 기계 검출률 **Wilson 95% 하한 > 인간 검출률 점추정** → **강등 성립** — 인간 검수를
     열등 기준으로 공식 강등, 6축이 안전 정본으로 승격(MEMORY 결정 로그로 확정).
   - 동시에 무결함 오검출(false alarm)의 Wilson 상한을 양측 병기(검출률만으로는
     "전부 결함이라고 외치는 검출기"가 이기므로).
4. **정직한 한계**: 이 증명은 주입 가능한 결함 유형에 한정된다. 상상 못 한 결함은
   S6 상시성 + 사후 행동 계측(답 미루기 도달 깊이·오개념 해소율 전수 계측 — 인간이
   원리적으로 못 하는 규모)이 담당한다.

### 3.3 crosswalk 승인 축 — 독립 구조 신호 (부분 대체·측정된 경계)

오개념 crosswalk(kebab↔M-id) 승인은 그동안 **인간 검수 전용**이었다(게이트 계약이
reviewer 서명 하드 요구). 여기에 §3 강등전을 적용하되, **정직한 재구성**이 필요하다:
매핑 정답성의 유일한 의미 신호(임베딩 코사인)는 이미 후보를 *제안*하므로 같은 코사인으로
*승인*하면 순환(독립 검증 아님)이다.

- **독립 신호(비순환)**: kebab이 문항 `distractor_map`에 쓰일 때 그 문항의 성취기준으로
  kebab 성취기준을 **역유도**해 M-id `standard_code`와 대조(`l4/misconception/
  crosslink_standard_signal.py`) — 코사인과 독립·완전 결정론·임베딩 0.
- **강등전**(`harness/crosslink_demotion_eval.py` + `crosslink_demotion_seeder.py`):
  by-construction 정답(M-id를 kebab에 직접 대응 저작·인간 라벨 0) + injected 오매핑 2 tier.
- **측정된 경계(실측 2026-07-09)**: cross-standard 오매핑 거부 **240/240·Wilson 하한 0.989**·
  정답 오거부 **0/4** — 성취기준을 가로지르는 오매핑은 기계가 자동 거부(인간 부하↓). 그러나
  same-standard 형제 오개념 오매핑은 **0/10**(false accept·구조축 못 잡음)·커버는 **5/34 kebab**
  (문항 미등장 29는 no_signal·인간 폴백). → **부분 대체**: 기계가 cross-standard·human-only
  경계를 *데이터로* 확정하고, 나머지는 인간 존치(6-⑥ "인간 폴백은 측정 미달·undecidable 구간만"의
  실현). 커버는 문항 코퍼스 성장 시 자동 확대.
- **게이트 계약 플립 보류**: `method=machine` 승인 허용은 이 측정이 인간 baseline을 넘는
  구간에 한해 별도 결정(자기승인 금지·이번은 측정 인프라 + 경계 보고까지).

## 4. 적용 제외 (검수가 아닌 것)

법정대리인 동의·변호사 검토·PII 보호는 "검수"가 아니라 **법적 의사표시·법률 판단**
(법령 유래 — 개인정보보호법 §22-2·저작권법)이라 본 기준의 관할 밖이다. 6축 달성
여부와 무관하게 존치한다.

## 5. 롤백 (되돌릴 수 있어야 안전)

강등 후에도 S5 감사(무작위 표본)의 롤링 결함율 상한이 **3% 초과** 시 해당 게이트를
자동 재잠금(인간 큐 복귀)한다 — 일방통행 금지. 재잠금·재해금은 전부 결정 로그.
