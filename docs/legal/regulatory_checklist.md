# 규제 준수 체크리스트 — WhyMath

> **출처**: MathScope PRD v1.1 §13.3~13.5(사이버학원 등록 검토·전자상거래법·광고 마케팅 규제)를 WhyMath 골격에 통합. PRD의 "MathScope" 표기는 "WhyMath"로 치환.
>
> ⚠️ **법률 단정 금지**: 이 문서는 *검토해야 할 규제 항목의 목록과 방향*이며 법률 자문이 아니다. "WhyMath가 사이버학원에 해당한다/안 한다", "이 약관이 적법하다"는 식의 *단정은 하지 않는다*. 모든 항목은 **변호사 자문을 거쳐 적용 여부·방식을 확정**한다.
>
> **자매 문서**: 개인정보·미성년자 동의는 `pipa_data_matrix.md`, 저작권은 `copyright_gradient.md`. 이 문서는 *사업 형태·전자상거래·광고*의 규제를 다룬다. 결제 약관 관련은 `docs/strategy/business_model.md` §7과도 교차.

## 1. 이 문서의 사용법

WhyMath는 *미성년자 대상*·*유료 구독*·*교육 서비스*라는, 규제가 겹겹이 적용될 수 있는 영역에 있다. CLAUDE.md 의사결정 우선순위 2번(법적·윤리적 준수)에 따라, **규제 검토를 "나중에"로 미루지 않는다**(`risks.md` 함정 6).

각 절은 *체크리스트*로 구성된다. 항목별로 (a) 무엇을 검토하는가, (b) 어느 Phase 전에 끝내야 하는가, (c) 변호사 자문 필요 여부를 명시한다.

## 2. 사이버학원 등록 검토 (PRD §13.3 / 학원법·교습소 관련)

> **핵심 질문**: WhyMath가 「학원의 설립·운영 및 과외교습에 관한 법률」(학원법)상 *등록·신고 대상*에 해당하는가?

### 2.1 쟁점

- 온라인으로 교습 콘텐츠·코칭을 *유료 제공*하는 서비스가 학원법상 *학원·교습소·과외교습* 중 무엇에 해당할 수 있는지, 또는 어디에도 해당하지 않는지 — **이것은 법률 판단 사항이며 변호사 자문 필수.**
- "사이버학원" 또는 "원격교습" 형태의 등록·신고 의무가 발생하는지, 발생한다면 어느 관할(교육청)에 어떤 절차로 하는지.
- WhyMath는 *AI 기반 진단·코칭 도구*라는 점에서 전통적 인강·학원과 성격이 다르나, **"다르다"는 것은 WhyMath의 주장일 뿐 법적 판단이 아니다.** 규제 당국·변호사의 해석을 확보해야 한다.

### 2.2 체크리스트

- [ ] WhyMath 서비스 형태가 학원법상 *등록·신고 대상*인지 법률 검토 → **변호사 자문 필수**
- [ ] 대상이라면 *관할 교육청·절차·요건*(시설·자격 등) 파악 → **변호사 자문 필수**
- [ ] B2C 단독 / B2B 학원 제휴 / B2B 학교 납품 — *형태별로* 규제 적용이 다를 수 있으므로 각각 검토 → **변호사 자문 필수**
- [ ] 등록 의무가 없다는 결론이 나더라도 *그 근거를 문서로* 확보(향후 당국 문의 대비)
- [ ] 교습비(수강료) 게시·신고 의무가 적용되는지 검토 → **변호사 자문 필수**

### 2.3 완료 시점

- **Phase 1.5 결제 시스템 출시 *전*** — 유료화 시작 전에 사업 형태의 법적 지위를 명확히 한다. 무료 β(Phase 1) 단계에서는 검토를 *시작*하되, 결론은 유료화 전 확정.

## 3. 전자상거래법·정기결제 (PRD §13.4)

> WhyMath의 B2C Freemium 유료 구독(`business_model.md` §2)은 「전자상거래 등에서의 소비자보호에 관한 법률」(전자상거래법)과 관련 고시의 적용을 받을 수 있다.

### 3.1 청약철회

- [ ] 유료 구독의 *청약철회권* 보장 — 기간·방식·예외 사유를 약관에 명시 → **변호사 자문 필수**
- [ ] 디지털 콘텐츠·서비스의 청약철회 *예외* 규정(이미 이용한 부분 등)의 적용 범위 검토 → **변호사 자문 필수**
- [ ] 청약철회 *절차를 앱 내에서 쉽게* 제공(소비자가 찾기 어렵게 숨기지 않는다 — CLAUDE.md "무자비한 게임화·중독성 설계" 금지 정신과 일관)

### 3.2 미성년자 환불

> 미성년자 결제는 특별한 보호 대상이다. `pipa_data_matrix.md` §3(14세 미만 법정대리인 동의)과 함께 검토한다.

- [ ] 미성년자가 법정대리인 동의 없이 한 결제의 *취소·환불* 절차 마련 → **변호사 자문 필수**
- [ ] 법정대리인이 *사후에* 결제 취소를 요청할 경우의 처리 절차 → **변호사 자문 필수**
- [ ] 결제 단계에서 *미성년자 여부·법정대리인 동의 여부*를 확인하는 UX 설계(`pipa_data_matrix.md` §3.2 동의 절차와 연동)
- [ ] 환불 절차를 *명확·신속*하게 — 미성년자 보호는 CLAUDE.md 의사결정 우선순위 1번(학생 안전·웰빙)에 직결

### 3.3 정기결제(구독) 고지

> 자동 갱신되는 구독은 *고지 의무*가 강화되어 있다(정기결제 관련 고시·가이드라인).

- [ ] 정기결제 *가입 시* — 결제 주기·금액·갱신 방식을 명확히 고지 → **변호사 자문 필수**
- [ ] 정기결제 *갱신 전* — 갱신 도래를 사전 통지(통지 시점·방식의 법정 요건 확인) → **변호사 자문 필수**
- [ ] 구독 *해지를 가입만큼 쉽게* 제공("다크 패턴" 회피 — 해지 버튼을 숨기거나 복잡하게 만들지 않는다)
- [ ] 무료 체험 → 유료 자동 전환 구조를 쓸 경우, 전환 시점·금액의 사전 고지 강화 → **변호사 자문 필수**
- [ ] 결제대행(PG)·간편결제(토스페이먼츠 등, CLAUDE.md 기술 스택) 연동 시 *PG사 약관·정산 조건* 검토

### 3.4 약관·표시 일반

- [ ] 이용약관·개인정보처리방침을 *가입 전* 제공하고 동의받는 절차
- [ ] 사업자 정보(상호·대표·연락처·사업자등록번호 등) 표시 의무 이행
- [ ] 가격·환불 정책을 *오해 없이* 표시(`business_model.md`·`market_positioning.md`의 가격 정책과 *문구 일치* 확인)

### 3.5 완료 시점

- **Phase 1.5 결제 시스템 출시 *전* 전 항목 완료.** 결제는 *법무 검토를 통과하지 못하면 출시하지 않는다*(CLAUDE.md 의사결정 우선순위 — 개발 속도가 7번, 법적 준수가 2번).

## 4. 광고·마케팅 규제 (PRD §13.5)

> WhyMath는 미성년자·학부모를 대상으로 마케팅하므로, 표시·광고 규제가 *엄격하게* 적용될 수 있다.

### 4.1 표시·광고의 진실성

- [ ] *학습 효과·성적 향상* 관련 광고 문구의 *근거 확보* — 입증 자료 없는 효과 주장 금지 → **변호사 자문 필수**
  - 특히 `risks.md` 핵심 가정 ②(개념 그래프가 성취도를 높이는가)는 *RCT로 검증 전까지* 광고에서 "성적이 오른다"고 단정하지 않는다. 검증 후에도 *과장 없이* 표현.
- [ ] 경쟁사(콴다 등) 비교 광고 시 *비교의 공정성·사실성* 확보 → **변호사 자문 필수**
- [ ] "1위", "최고", "유일" 등 *최상급 표현*의 근거 확보 → **변호사 자문 필수**

### 4.2 미성년자 대상 마케팅

- [ ] 미성년자의 *심리를 압박*하거나 *불안을 조장*하는 마케팅 금지 — CLAUDE.md "부정적 피드백을 정서적으로 강화하는 표현 금지" 정신을 *마케팅에도* 적용
- [ ] 미성년자에게 *결제를 직접 유도*하는 표현 자제(결제 주체는 학부모 — `market_analysis.md` §1.2)
- [ ] 게임화 요소를 *마케팅 후크*로 과장하지 않는다(CLAUDE.md "무자비한 게임화·중독성 설계" 금지)

### 4.3 추천·후기·인플루언서

- [ ] 이용 후기·추천 마케팅 시 *대가성 표시*(경제적 이해관계 공개) 의무 이행 → **변호사 자문 필수**
- [ ] β 사용자 후기 활용 시 *동의*와 *진실성* 확보

### 4.4 개인정보를 이용한 마케팅

- [ ] 마케팅 목적 개인정보 이용·광고성 정보 전송 시 *별도 동의* — `pipa_data_matrix.md`와 연계, CLAUDE.md "미성년자 개인정보를 분석·마케팅 외부 공유 금지"와 직결 → **변호사 자문 필수**
- [ ] 광고성 정보 전송 시 표시 의무(제목·수신거부 방법 등) 이행

### 4.5 완료 시점

- 마케팅 *집행 전* 검토. Phase 1 무료 β는 *오가닉·지인 중심*(`business_model.md` §2.3 CAC 메모)이라 광고 규제 노출이 적으나, Phase 1.5+ 유료 광고 도입 시 전 항목 검토 완료.

## 5. 통합 체크리스트 — Phase별 게이트

> 아래는 *규제 검토의 Phase별 마감*을 한눈에 본다. 각 항목의 상세는 위 해당 절 참조.

| Phase | 마감해야 할 규제 검토 | 근거 절 |
|---|---|---|
| **Phase 1 (무료 β)** | 사이버학원 등록 검토 *착수*. 개인정보 동의 절차 설계(`pipa_data_matrix.md`) | §2 |
| **Phase 1.5 (결제 출시) 전** | 사이버학원 등록 *결론 확정*. 전자상거래법 전 항목(청약철회·미성년자 환불·정기결제 고지·약관) | §2, §3 |
| **Phase 1.5+ (유료 광고) 전** | 광고·마케팅 규제 전 항목 | §4 |
| **Phase 3~4 (B2B 본격)** | B2B 학원·학교 계약 규제, 사업 형태별 재검토 | §2.2, `business_model.md` §7 |

> **핵심 원칙 재확인**: Phase 1.5 결제 출시는 §2·§3의 변호사 검토를 *통과하지 못하면 미룬다*. 게이트 미달 시 Phase 연장이 기본(`risks.md` "게이트 미달 대응").

## 6. 변호사 자문 필요 사항 (통합 체크리스트)

- [ ] WhyMath 사업 형태의 학원법상 지위(등록·신고 대상 여부) → **변호사 자문 필수**
- [ ] 유료 구독의 청약철회권 보장 범위·디지털 콘텐츠 예외 → **변호사 자문 필수**
- [ ] 미성년자 결제 취소·환불 절차 → **변호사 자문 필수**
- [ ] 정기결제 가입·갱신 고지 의무의 법정 요건 → **변호사 자문 필수**
- [ ] 학습 효과·성적 향상 광고 문구의 적법성·근거 요건 → **변호사 자문 필수**
- [ ] 비교 광고·최상급 표현의 근거 요건 → **변호사 자문 필수**
- [ ] 추천·후기 마케팅의 대가성 표시 의무 → **변호사 자문 필수**
- [ ] 마케팅 목적 개인정보 이용·광고성 정보 전송 동의 → **변호사 자문 필수** (`pipa_data_matrix.md`와 통합 검토)
- [ ] B2B 학원·학교 계약의 규제·데이터 위탁 관계 → **변호사 자문 필수** (`business_model.md` §7·`pipa_data_matrix.md` §5와 통합)
- [ ] 이용약관·개인정보처리방침 *초안 전체* 법률 검토 → **변호사 자문 필수**
