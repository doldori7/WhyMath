## §2. 매핑 기준 (재현 가능성 — 어떤 필드로 앵커에 귀속시켰는가)

**매핑 축 = 성취기준 코드 단일 축** (2022 개정·대학은 자체작성 코드). 원자(`standard_codes`)·
오개념(`standard_code`)·문항(`achievement_standard_codes`)이 모두 이 필드를 가져 세 자산을
같은 축으로 귀속시킬 수 있다. 대안이던 소단원명(subunit) 축은 ① 구조 헤더 노드
(`level=소단원`, `standard_codes=[]` — 예: `중변관-U1-S13` "이차방정식")가 섞이고 ② 교과서
단원 granularity가 달라(예: '비와 비율' subunit은 비례식·비례배분 원자까지 포함) 채택하지

## §3. 축별 상세·특기 사항

### 3.1 원자 노드
- 전 앵커 귀속 원자는 모두 `level=세부개념` 리프다(단원·소단원 구조 노드 0).
- **A4(깊이 앵커)의 원자가 3개로 전 앵커 최소** — `9수02-20-1`(양변 나눗셈 함정)·
  `9수02-20-2`(풀이)·`9수02-20-3`(근과 x절편). 150 CU를 생산할 깊이 앵커의 개념 해상도가
  이 3개로 충분한지는 콘텐츠 판단 사안이다(데이터만 제시).
- A7·A8 원자는 **존재한다**(8·5개) — 대학 원자 백본은 이미 1,069노드(전체의 40%)로 적재돼
  있고, 선언서가 우려한 "대학 앵커 자산 부재"는 원자·성취기준 축에는 해당하지 않는다.

### 3.2 성취기준
- 학교급 앵커(A1~A6)는 전부 2022 개정 코드로 매핑됐다(2027년 재작업 방지 요건 충족).
- 대학 앵커(A7·A8)의 성취기준은 국가 교육과정이 아니라 **와이매스 자체작성**
  (`standards_university_v1`, 2026-06-22 통합마스터 유래 — `source_document` 필드 명기)이다.

### 3.3 오개념 (M-id DB)
- A4=8건·A6=8건·A1=4건·A3=4건·A2=2건·A5=2건 · **A7=A8=0건**. 오개념 DB 843행은 전부
  초·중·고 학교급이다(`school_level` 분포에 '대학' 없음 — 결과 JSON `global.misconceptions`).
- 행 품질 편차 존재: 예로 A4의 M0407·M0573은 `error_type`이 공란이다(건수에는 포함).

### 3.4 기계판정형 detection_rule
- **리터럴 `detection_rule` 필드는 오개념 843행 전수에서 0건, 저장소 코드 디렉터리에서도
  0건**(§6 판정). 즉 5축 중 이 축은 어느 앵커에도 실재 자산이 없다.
- 실재하는 최근접 대응물 = L4 오개념 카탈로그(`l4/misconception/catalog.py`, kebab 64종)의
  탐지 채널 3계: substring `signals`(64종 전부) < `regex_signals`(4종) < SymPy
  `canonical_wrong_form`(2종, `wrong_form_match.py`가 shadow 전용으로 런타임 배선). 여기에
  crosswalk(`misconception_crosslinks_v1` 64행, 전량 manual·검수 완료)로 M-id와 1:1 연결.
- 앵커 귀속: **A4=3종·A6=2종, 전부 substring 채널뿐** — 기계채널(정규식·SymPy) 보유 5종
  (distribution-over-power [9수02-19]·exponent-zero [9수02-08]·square-root-positivity
  [9수01-07]·fraction-cancellation [9수01-04]·log-distribution [12대수01-05])은 **전부 앵커
  코드 밖**이다. 선언서 B6("앵커 커버분이 정규식/SymPy 술어로 자동 판정")는 어떤 앵커
  조합을 골라도 신규 구축이다.

### 3.5 문항 코퍼스
- **문항이 있는 앵커는 A4(378)·A6(261) 둘뿐**이다. A4는 conceptual 48 + generated 184 +
  rephrased 146; A6은 conceptual 24 + generated 140 + rephrased 97 (결과 JSON `per_bank`).
- **A6의 261문항은 6코드 중 [12미적Ⅰ-02-07](증가감소·극대극소) 한 코드에 전량 집중**
  — 접선·평균값·개형·방정식부등식·속도가속도 5코드는 0(부록 B).
- A1·A2·A3·A5·A7·A8=0의 진위 검증(매핑 오류 아님 — 부록 B 명령으로 재현):
  `problem_bank_probability_finite_v0` 34문항은 고교 확률과 통계([12확통01/02-*])라 A3(중2)에
  안 걸리고, `problem_bank_killer_v0` 120문항은 고1 근과 계수([10공수1-02-03])·삼차사차
  ([10공수1-02-07])라 A5(최대최소)에 안 걸린다. 즉 0은 단원 부재이지 집계 누락이 아니다.
- 인접 자산(범위 확장 시 편입 후보 — 부록 B): A4 인접 인수분해 [9수02-19] 96문항,

  목록은 결과 JSON `excluded_self`) 결과 정규식 `\bOP_0[1-8]\b`의 출현은 **문서 1파일**
  (`backlog/tasks/EOS-52-anchor-asset-audit.yaml` — 본 태스크 자신)뿐이다. **코드 디렉터리
  (src·scripts·tests·schemas·infra) 0건, 데이터(data/) 0건.** 즉 `OP_01~08`이라는 명명
  체계는 코드로 실재하지 않는다.
- **기능적 대응물은 실재한다**: L4 `l4/misconception/distractor.py`의
  `DistractorOpCode`/`DISTRACTOR_CATALOG` — **kebab-case 추상 오류연산 op-code 10종**
  (`select-opposite-root`·`factor-sign-flip-root`·`root-loss-divide-by-variable`(이상 A4 귀속),
  `select-opposite-extremum`·`report-x-coordinate-for-value`(이상 A6 귀속), 외 5종은 앵커 밖).
  `schema/problem.py`의 `DistractorEntry.op_code`(선택 필드)로 문항 distractor_map에 배선되고
  L4 검증자가 참조 무결성을 검사한다. 선언서 부록 C의 CU 정의("예상 오답 3개(OP코드)")를
  실행하려면 **이 kebab 체계를 쓰거나 OP_nn 명명을 새로 정의**해야 하며, 후자라면 기존
  10종과의 매핑이 필요하다.
- 부기(표기 지연 관찰): `distractor.py` 하단 docstring은 "8종", 상단 주석은 "10종"으로
  서로 다른데 실측은 10종이다. `catalog.py` docstring의 "34종"도 실측 64종과 다르다(데이터
  문제가 아니라 docstring 갱신 누락 — 별도 처리 사안).

python3 - << 'EOF'
import glob
import json
from collections import Counter

groups = {
    "A4 인접(인수분해)": ["[9수02-19]"],
    "A5 인접(고1 이차·삼차사차방정식)": ["[10공수1-02-02]", "[10공수1-02-03]", "[10공수1-02-07]"],

    "A6 앵커 내 코드별": [f"[12미적Ⅰ-02-{i:02d}]" for i in range(5, 11)],
}
c = Counter()
for f in glob.glob("data/corpus/problem_bank_*/problems.jsonl"):
    for line in open(f, encoding="utf-8"):
        if line.strip():
            for k in json.loads(line).get("achievement_standard_codes") or []:

for label, codes in groups.items():
    print(label, {k: c.get(k, 0) for k in codes}, "| 합계:", sum(c.get(k, 0) for k in codes))
EOF
