# 검정 교과서 매핑 스키마

> 본문 X, 목차·구조만.

## 활용 범위

✅ 가능:
- 단원명·차시명 (사실정보)
- 페이지 범위
- 학습 순서
- 출판사·저자 표시

❌ 불가:
- 본문 복제
- 예제·풀이 복제
- 그림·그래프 복제
- 폰트·디자인 복제

## 13종 (시장 점유율 추정)

중학교:
- 천재교육·비상교육·미래엔·금성·동아·신사고·지학사 등

고등학교:
- 천재교육·비상교육·미래엔·금성·신사고·동아·지학사·교학사·EBS·법문사 등

(Phase 1: 상위 5종 우선)

```yaml
publisher: "천재교육"

authors: ["...", "..."]
isbn: "978-..."

    sub_units:
      - number: "1-1"
        title: "소인수분해"
        pages: "12-25"
        standard_codes: ["[9수01-01]", "[9수01-02]"]
```

## 수집 방법

1. 출판사 공식 사이트 (목차 PDF·HTML)
2. 도서관 메타데이터 (국립중앙도서관·국회도서관)
3. 학교알리미 (학교별 채택 정보)

## 검증

- 출판사·저자·ISBN 일치
- 단원 순서 누락 없음
- 성취기준 매핑 *학회·연구* 출처 확인
