## 2. 스키마

`data/corpus/achievement_criteria_v1/achievement_criteria.json` — 배열, 원소 13개(학교급×과목):

```jsonc
{
  "school_level": "고등학교",           // "고등학교" | "초중학교"
  "subject": "공통수학",                 // 과목명 또는 학년군명
  "unit_hierarchy": ["(1) 문자와 식", "(가) 다항식의 연산", ...],   // 단원/소단원 제목만(원문 짧은 헤더)
  "standard_criteria_coverage": [
    {"standard_code": "[10수학01-01]", "criteria_codes": ["[10수학01-01-00]"]}
    // 성취기준 코드 → 평가준거 성취기준 코드 목록(코드만, 설명 문장 없음)
  ],
  "achievement_levels_by_unit": [
    {"unit": "(1) 다항식", "levels": ["A","B","C","D","E"]}
    // 단원 → 그 단원에 정의된 성취수준 등급 라벨 집합만(서술 없음)
  ]
}
```

## 3. 라이선스·안전 (CLAUDE.md 우선순위 #2 — 미확정 상태를 정직하게 반영)

**공공누리 유형이 확인되지 않았다.** PDF 표지에는 "본 자료 내용의 무단 복제를 금함"이라는 문구만
있고, 텍스트 추출로는 공공누리(KOGL) 로고·유형 표시가 발견되지 않았다(로고가 이미지일 가능성 있음
— 미확인이지 부재 확정이 아님). NCIC 게시판(원출처, 이 세션에서는 네트워크 차단으로 확인 불가)에서
실제 공공누리 유형을 확인하기 전까지, 이 코퍼스는 **구조 메타데이터로 범위를 제한**한다:

| 대상 | 반입 여부 | 사유 |
|---|---|---|
| 단원/소단원 제목(`unit_hierarchy`) | ✅ 반입 | 짧은 구조 라벨, 사실정보에 가까움 |
| 성취기준·평가준거 코드(`standard_criteria_coverage`) | ✅ 반입 | 코드는 식별자, 이미 `standards_v1`(공공누리 1유형 확정)에 있는 공식 성취기준 코드와 동일 체계 |
| 성취수준 등급 라벨(`achievement_levels_by_unit`의 `levels`) | ✅ 반입 | A~E/A~C 단독 문자, 구조 신호 |
| **평가기준 설명 문장**(상/중/하 각 서술) | ❌ 비반입 | KICE 연구진이 직접 저술한 본문 — 저작권 확인 전 반입 금지(CLAUDE.md "교과서 학습목표 텍스트 인용은 변호사 검토 전제"의 동형 적용) |
| **성취수준 일반적 특성 서술**(A~E 각 문단) | ❌ 비반입 | 상동 |
| **예시 평가도구 문항·채점기준**(`다.` 절) | ❌ 비반입 | 상동, 특히 문항은 저작물성이 더 명확 |

**후속**: 공공누리 유형이 NCIC 게시판 또는 KICE 공식 확인으로 밝혀지면, 원본 PDF를 재확보해 본문
서술까지 반입하는 후속 태스크를 별도 등재한다(이 코퍼스는 덮어쓰지 않고 버전 올림).

## 4. 추출 방법 (best-effort — 완전성 보증 없음)

`pdfplumber` 텍스트 추출 + 정규식(단원 헤더 `(1)`/`(가)` 패턴, `[...]` 코드 패턴, 성취수준 등급
단독 문자 A~E) — 표 레이아웃을 직접 파싱하지 않고 텍스트 순서 휴리스틱을 쓴다. 알려진 한계:

- 코드→평가준거코드 매핑은 "직전 최상위 코드에 하위 코드 귀속" 방식이라, 페이지 경계에 걸친 표에서
  간헐적으로 오귀속 가능(예: `[12수학Ⅱ01-02]`에 `[12수학Ⅱ01-03-00]`이 잘못 붙는 사례 확인)
- 수학Ⅰ·고급수학Ⅰ·초등 1~2학년군은 "단원/영역별 성취수준" 절이 탐지되지 않음(`achievement_levels_by_unit: []`)
  — 원문 형식이 다르거나 파싱 실패, 원인 미조사(§`_provenance.json` `known_gaps`)
- 고등학교 진로선택 3과목(기하·경제 수학·수학과제 탐구)은 **원본 보고서 자체에 없음**(2017년 보고서
  범위 밖) — 날조하지 않고 코퍼스에서 제외

이 코퍼스는 스키마 설계용 "실측 재료"이지 완결된 정본이 아니다(CUR-03 acceptance ④ — 스키마 확장은
범위 밖, 별도 후속 태스크).
