# /dataset — 데이터셋 작업

## 임무
새 데이터 소스의 *라이선스 안전성·구조·신뢰도*를 검증한 후 수집·정제·저장 파이프라인을 설계한다.

## 실행 절차

### 1. 소스 분류
| 소스 | 라이선스 | 처리 방식 |
|---|---|---|
| **NCIC 성취기준** | 공공누리 1유형 | 크롤링 가능 |
| **학교알리미** | 공공 | 크롤링 가능 |
| **평가원 기출** | 공공·교육용 인용 | 크롤링 + 출처 명시 |
| **EBS 메타데이터** | 단원·차시명만 | 본문 X, 매핑만 |
| **검정 교과서 목차** | 사실정보 | 단원명만 |
| **검정 교과서 본문** | ❌ 절대 금지 | 사용 불가 |
| **CK-12 / OpenStax / Siyavula** | CC BY | 활용 가능, 출처 명시 |
| **NRICH** | 무료(상업은 협의) | 영감만, 직접 사용 X (현재) |
| **AoPS Wiki** | CC BY-SA | 활용 가능, Share-Alike |
| **NuminaMath** | Apache 2.0 | 자유 사용 |
| **MathNet (MIT 2026)** | 확인 필요 | 라이선스 확인 후 |
| **사용자 풀이** | 동의 필수 | 동의 절차 후 |
| **학원·인강 자료** | ❌ 금지 | 사용 불가 |

### 2. 사전 점검 체크리스트

```
[ ] 라이선스 확인되었는가? (docs/data/licensing_safety.md)
[ ] 상업적 활용 가능한가?
[ ] 출처 표시 의무 있는가?
[ ] 가공·재배포 가능한가?
[ ] PII (개인식별정보) 포함되는가?
[ ] robots.txt 준수하는가?
[ ] 수집 속도 제한 (rate limit) 준수하는가?
```

### 3. 데이터 카드 작성

```markdown
# 데이터셋: [name]

## 메타데이터
- 소스: [URL]
- 라이선스: [type]
- 수집일: [date]
- 크기: [N rows, M MB]
- 신뢰도: ★★★★★

## 스키마
| 필드 | 타입 | 설명 |
|---|---|---|
| ... | ... | ... |

## 알려진 제약
- ...

## 라이선스 요구사항
- 출처 표시: [방법]
- 가공 가능: Yes/No
- 상업적 활용: Yes/No

## 가공 단계
1. ...
2. ...

## 검증 결과
- 샘플 N개 사람 검수: ★/5
- 자동 검증 통과율: X%
```

### 4. 파이프라인 설계

```python
# 표준 파이프라인 구조
1. 수집 (collect)
   - HTTP 요청 또는 파일 입력
   - 속도 제한 준수
   - 재시도 정책

2. 정제 (clean)
   - 인코딩 통일 (UTF-8)
   - 중복 제거
   - 결측 처리

3. 정형화 (transform)
   - 스키마 적용
   - 정규화

4. 검증 (validate)
   - 스키마 검증
   - 비즈니스 룰 검증
   - 샘플 사람 검수

5. 저장 (load)
   - PostgreSQL (정형)
   - ChromaDB (임베딩)
   - S3/로컬 (원본 아카이브)

6. 인덱싱 (index)
   - 검색용 인덱스
   - 캐싱
```

### 5. 출력 산출물

```
✅ 데이터셋 작업 완료: [name]

생성된 파일:
- docs/data/[name].md (데이터 카드)
- src/data-pipeline/[name]/
  ├── collect.py
  ├── clean.py
  ├── transform.py
  ├── validate.py
  └── load.py
- tests/data/test_[name].py

수집 결과:
- 원본: N rows
- 정제 후: M rows
- 검증 통과: P%

라이선스 점검: ✅ 모든 요구사항 충족

다음 단계:
> ChromaDB 임베딩 시작
> 또는 다음 데이터셋
```

## 원칙

### 라이선스 우선
- 코드 작성 *전에* 라이선스 확인
- 회색 영역이면 *사용 안 함*이 기본값
- 협상 가능한 영역은 *기록* 후 다음 페이즈

### 데이터 카드는 필수
- 모든 데이터셋은 *카드* 동반
- 카드 없는 데이터 = 사용 불가

### 검증을 항상 동반
- 자동 검증 (스키마·룰)
- 사람 검수 (샘플 5%)
- 둘 다 통과해야 production

### 출처 표시 자동화
- 모든 콘텐츠 출력에 *자동 출처* 부착
- 사용자에게 보이지 않더라도 *내부 로그*는 유지

## 절대 금지

❌ 검정 교과서 본문·예제 직접 수집  
❌ EBS 영상 자막·교재 본문 수집  
❌ 학원·인강 자료 수집  
❌ 사용자 데이터 *동의 없이* 학습용 활용  
❌ 미성년자 PII를 분석·마케팅에 사용  
❌ 출처 표시 의무 무시
